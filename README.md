# Dewu

[下载 Windows 便携包](https://github.com/Hxxdsk/Dewu/releases/latest/download/Dewu-Windows.zip)

## 使用教程

1. 下载并完整解压 ZIP，双击 `Dewu/得物工具箱.exe` 即可使用。请将 `_internal` 文件夹和 EXE 放在一起。
2. **优先使用 ego 浏览器，其他浏览器暂未做适配。** 使用自动查询或下载前，请在 ego 中登录对应网站。
3. **发货预警**：选择结果保存位置，可立即执行，也可设置每日运行时间。
4. **商品编码匹配**：输入款号，点击「下载并匹配」，或手动选择聚水潭与得物导出表。确认模糊配对后导出。
5. **Dickies 送审状态**：粘贴开发款号并查询，可筛选、复制、修改及批量送审。
6. 如需使用新品资料导出插件，解压便携包内的 `dewu-export.zip`，在 ego 的扩展管理页启用开发者模式，加载解压后的扩展文件夹，然后刷新得物「申请新品」页。
